- **실행 방법:** 사용자가 "N월 명세서 만들어줘"라고 하면 스킬 `prepaid-expense-schedule`을 부른다. 또는 아래 명령을 바로 실행한다.

## 2. 입력

- 원자료 Excel의 첫 번째로 조건에 맞는 시트(현재 `Sheet`)를 쓴다. 1행이 헤더이고, 2행부터 데이터다.
- 데이터는 시작시간과 금액이 있는 행이 이어지는 데까지다. 그 아래 SUBTOTAL 합계 행은 제외한다.
- 열은 **헤더 이름으로** 찾는다(스크립트의 `COLS`). 열 순서가 바뀌어도 된다.

| 키 | 헤더 후보 | 필수 | 비고 |
|---|---|---|---|
| close | 결산일자 | | 원장 대사 기준일. 없으면 기준일로 대사 |
| voucher | 전표번호 | | |
| date | 회계일자, 전표일자 | | 지급일. 이 날 전인 달은 월말 잔액 0 |
| acct | 계정과목명, 계정명 | ✔ | 계정별 요약 기준 |
| vendor | 거래처명 | | |

## 3. 실행 인자

```
build_schedule.py <원자료.xlsx> [--base-date YYYY-MM-DD] [--sheet 시트명] [--out 경로] [--out-sheet 명세서] [--no-backup]
```
- `--base-date`: 기준일(월말). 생략하면 결산일자 중 가장 많은 값을 쓰고, 결산일자도 없으면 전월말을 쓴다. **기준일이 파일 이름의 연월도 정한다.**
- `--out`: 생략하면 `<원자료 폴더>/선급비용명세서('YY.M).xlsx`. 같은 월 파일이 있으면 덮어쓴다. 덮어쓰기 전에 사용자에게 알린다.
- `--out`을 원본 경로로 주면 원본에 시트를 추가한다. 이때 `_백업_<시각>` 파일을 자동으로 만든다. 사용자가 명시적으로 요청했을 때만 쓴다.
- 결과 파일에는 원자료 시트들의 복사본과 '명세서' 시트가 함께 들어 있다. 명세서 수식은 같은 파일 안의 원자료를 참조한다.
- 결과 파일이 Excel에서 열려 있으면 PermissionError가 나고 안내 메시지를 낸 뒤 종료한다.

## 4. 계산 규칙 (Excel 수식과 Python 검증이 같은 로직)

기호: G = 발생금액, H = 시작일시, I = 종료일시, X = 기준 월말 날짜

| 항목 | 식 |
|---|---|
| 총기간(분) J | `ROUND((I-H)*1440,0)` |
| X 시점 잔여분 | `ROUND(MAX(0, I - MAX(X+1, H))*1440, 0)` — X+1은 X일 24:00 |
| X 시점 잔액 Bal(X) | `ROUND(G * ROUND(잔여분/J, 5), 0)` |
| 월 m의 비용 | `Bal(전월말) - Bal(당월말)` |
| 기준일 잔액 | `ROUND(G * 잔여비율, 0)`, 비용누계 = G − 잔액 |
| 월말 잔액 표 | `IF(월말 < 회계일자, 0, Bal(월말))` |
| 원장 대사 | `Bal(결산일자) - ABS(발생계산금액)` → 0이어야 함 |

원장 비율의 예: 59,372,568 × ROUND(132,479 / 525,599, 5) = 59,372,568 × 0.25205 = 14,964,856. 원장 금액과 같다.

## 5. 출력: '명세서' 시트 구성

**상단 (5행 헤더, 6행부터 건별, 그다음 합계 행)**
- A~F: No, 전표번호, 회계일자, 계정과목명, 거래처명, 적요. 원자료를 참조하며 녹색 글자다.
- G: 발생금액.
- H~I: 시작시간, 종료시간. 텍스트와 날짜값 모두 처리하는 수식이다.
- J~L: 총기간(분), 기준일 잔여기간(분), 기준일 잔여비율.
- M부터: 월별 발생 비용. 범위는 최초 시작월부터 최종 종료월까지다. 현재는 2025.11~2027.05, 19개 열(M~AE)이다.
- 그다음 열: 월별비용 합계(=발생금액), 기준일까지 비용 누계, **기준일 선급비용 잔액**.
- 원장 대사 열(녹색 헤더): 원장 결산일자, 원장 잔액, 결산일자 기준 재계산 잔액, 차이. 차이가 0이 아니면 빨간 글씨다.
- 합계 행 아래에 [계정과목별 요약](SUMIF)이 있다.

**하단**
- [월별 선급비용 잔액]: 건별 월말 잔액. 월 열 위치는 상단과 같다.
- 검증 열: 기준일 월의 잔액에서 상단의 기준일 잔액을 뺀 값. 0이어야 한다.
- 합계 행과 [계정과목별 월별 잔액 요약]이 있다.

**공통 서식**
- C2에 기준일이 있다. 노란 셀, 파란 글자이며, 바꾸면 전체가 다시 계산된다.
- 기준일 이전 월은 노란 음영, 잔액 표의 기준일 월은 붉은 음영이다.
- 글꼴은 맑은 고딕 10이다. 금액 서식은 `#,##0;-#,##0;"-"`이다.
- 틀 고정은 M6이다. `fullCalcOnLoad=True`로 저장한다.

## 6. 검증 (스크립트 stdout)

- 저장 경로, 원자료 행 범위, 건수, 기준일, 월 범위를 출력한다.
- 기준일 잔액 합계와 계정별 잔액을 출력한다.
- 월별 비용 합계가 발생금액과 같은지, 원장 대사가 맞는지 판정하고, 맞지 않으면 행 번호와 차이 금액을 출력한다.
- 월별 발생비용과 월말 잔액 표를 출력한다.
